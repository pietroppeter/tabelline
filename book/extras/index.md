# gt-extras

Examples of [gt-extras](https://posit-dev.github.io/gt-extras/), the plots, icons and themes that
the gt-extras contributors add to Great Tables, MIT licensed. Each keeps the code of the original,
in Python, with the same table made with gtExtras and gt in R (written for the book) and with
tabelline in Nim; the book's own remarks are in boxes marked “× tabelline”.

What tabelline lacks to do what these examples do is collected in [What the port found](../gaps.html).
