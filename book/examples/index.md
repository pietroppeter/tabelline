# Great Tables: examples

The [Examples](https://posit-dev.github.io/great-tables/examples/) of Great Tables, by Rich
Iannone, Michael Chow and the Great Tables contributors, MIT licensed: tables made from start to
finish, each with its code. Each keeps the code of the original, in Python, with the same table
made with gt in R (written for the book) and with tabelline in Nim; the book's own remarks are in
boxes marked “× tabelline”.

What tabelline lacks to do what these examples do is collected in [What the port found](../gaps.html).
