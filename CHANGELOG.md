## Unreleased

- Docs: The Great Explainer's first table builds *la tavola pitagorica* from scratch, with
  `collect` from `std/sugar` and a `for` loop, before using it; `tavolaPitagorica(n)` is
  introduced later, as the same data ready made (#PR).
- Docs: Munari is the base look of every page, so a page without JavaScript is Munari; the
  quaderno stays as the other look, every rule of it scoped by `html[data-tema="quaderno"]`
  (#24).
- **Breaking (before 0.1):** `optTokens()` is renamed `optPageTheme()`, a name a gt user can read;
  the home page says what it does, and The Great Explainer has a section on it, *Tables that follow
  the page* (#21). The home page and the README no longer carry the status warning: the
  Roadmap and the Coverage map say where tabelline is (#21).
- Docs: the devlog post *Milano Cortina 2026, in small numbers*, the 0.1 use-it post: the Winter
  Olympics and Paralympics in 28 tabelline tables, with data from Wikipedia, NOAA and the SGR report
  (`docs/devlog/data/milano-cortina/`, regenerated by its `fetch.py` and `co2.py`) and facts reported by
  Il Post (`docs/olimpiadi.nim`).
- Book: the tabelline book, a nimibook in `book/` in the Munari look with the Edo palette (the tokens of `docs/stile.nim`):
  the Great Tables *Get Started* guide ported page by page (14 pages), each example in 👑 Nim
  next to the original 🐍 Python and the same in 🏴‍☠️ R with gt, each with its table, *What the port found* (the gaps), and *What the book will port*: every planned source (Great
  Tables blog and examples, gt's guides and case studies, gt-extras), page by page, with the release
  that can port it (`book/plan/plan.py`); built
  incrementally, deployed at `/book/` (#11).
- **Breaking (before 0.1):** `optQuaderno()` is replaced by `optTokens()`, a preset whose colours
  are CSS variables of the page (`var(--n-9, #1C1C1C)`, …), so a table follows the page's palette (#19).
- Docs: every page is made of blocks. `docs/stile.nim` holds the palette by roles (six values per
  look, every other colour mixed from them) and the CSS of both looks; `docs/blocchi.nim` holds
  the blocks (`nbTitolo`, `nbNota` with a kind enum and the warning triangle, `nbCards`,
  `nbGalleria`, `nbTabs`, `nbShowCode`, `nbParti`, `nbAccanto`, `nbTinte`, `nbParte`); pages have
  no HTML, styles or colours of their own, and `tools/drift.nim` checks it in CI. The Design Ref
  is rewritten around the blocks, in three coloured parts (#19).
- Docs: devlog post *Blocks, not HTML*, and a first custom block module `docs/blocchi.nim`
  (`nbGalleria`, `nbScheda`; their CSS in the theme).
- Docs: devlog post *Reviewing the design: a palette by roles*, the proposal for the new
  Design Ref.
- Docs: a new structure. The home page keeps one simple table and lists the living documents
  in reading order (The Great Explainer, Devlog, Book, Roadmap, Coverage map, Design Ref,

- Fix: `dataColor` colours each column on its own range, numbers as numbers next to a text
  column, and a domain from high to low runs the palette the other way; the heading and column
  labels get white text on dark backgrounds by contrast, so `optStylize(2, "red")` reads (found by
  the 0.1 port thread).

- Docs: the three devlog posts of the 0.1 use-it thread (*A month of building, as an operetta*,
  *Operetta, a first sketch*, *Skills, from the beginning*, #9) left the devlog: they are about the

  `optFootnoteMarks` (with `"extended"` marks and marks of your own), `optFootnoteSpec`,

- Docs: the devlog post *Designing tabelline 0.1*; the coverage map marks the 24 groups done.
- Docs: a coverage map of tabelline against gt and Great Tables (85 feature groups), with the

- Docs: the roadmap (living document, from `docs/piano.nim`): releases 0.1 to 0.5 and three

## 0.1.0 (7 Nov 2026)

The first release: a proof of concept. The API will change.

- The table data (`Value`, `TableData`, `tableData:`, CSV), the table spec (`Tabella`) with the
  six parts of gt (header, column labels and spanners, stub and stub head, row groups, body,
  footer), 11 formatters and `fmtBar`, substitutions, styles at locations, `dataColor`,
  `tabOptions` and presets (`optStylize`, `optQuaderno`, ...), HTML / text / Markdown renderers
  and the nimib block `nbTable`. Datasets: `planets`, `exibble`, `tavolaPitagorica`. (#1)
- Repository setup: OpenSpec specs with runnable examples, the spec page, the explainer, the
  devlog, the quaderno theme and CI for tests, examples and pages. (#1)
- Dependencies with atlas (`atlas.lock`, `nim.cfg`, nimib as the optional `docs` feature) and
  `tools/setup.sh`, which sets up a laptop, CI or a fresh coding-agent sandbox. Needs Nim 2.2
  or later. (#2)
- Docs: an "R or Python?" section and a note on `sink` in the explainer (#2); the devlog post
  *Tabellone: when a table becomes a grid* (#3); backlog ideas from using tabelline in
  diagrammari (#4).
- Docs: a second look for the pages, after Bruno Munari, and the default; the quaderno is a
  switch away in every header, and the choice is remembered. Devlog post *Two looks*. (#5)
